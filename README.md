# 📝 Todo App - Список дел

Современное веб-приложение для управления задачами, построенное на React и Vite. Приложение предоставляет интуитивный интерфейс для создания, редактирования и управления списком задач с сохранением данных в локальном хранилище браузера.

## ✨ Основные возможности

- ➕ **Добавление задач** - быстрое создание новых задач с валидацией
- ✏️ **Редактирование задач** - встроенное редактирование с сохранением изменений
- ✅ **Отметка выполнения** - переключение статуса задачи одним кликом
- 🗑️ **Удаление задач** - удаление с плавной анимацией
- 🔍 **Фильтрация** - просмотр всех, активных или завершённых задач
- 📊 **Статистика** - отображение общего количества, активных и завершённых задач
- 🧹 **Очистка завершённых** - массовое удаление всех выполненных задач
- 💾 **Сохранение в LocalStorage** - автоматическое сохранение данных в браузере
- 🎨 **Современный UI** - красивый интерфейс с плавными анимациями
- 📱 **Адаптивный дизайн** - оптимизация для мобильных устройств

## 🛠️ Технологический стек

- **React** 19.2.0 - библиотека для создания пользовательских интерфейсов
- **Vite** 7.2.4 - быстрый сборщик и dev-сервер
- **CSS Modules** - изолированные стили для каждого компонента
- **LocalStorage API** - локальное хранилище данных

## 📦 Установка

### Предварительные требования

- Node.js (версия 18 или выше)
- npm или yarn

### Шаги установки

1. Клонируйте репозиторий:

```bash
git clone https://github.com/vasilyefff/react-todo-app.git
cd react-todo-app
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите dev-сервер:

```bash
npm run dev
```

4. Откройте браузер по адресу `http://localhost:5173`

## 🎯 Как использовать

1. **Добавление задачи**: Введите текст задачи в поле ввода и нажмите кнопку "Добавить" или клавишу Enter
2. **Редактирование задачи**: Нажмите кнопку ✏️ рядом с задачей, внесите изменения и нажмите 💾 для сохранения или ❌ для отмены
3. **Отметка выполнения**: Установите галочку рядом с задачей для изменения её статуса
4. **Удаление задачи**: Нажмите кнопку 🗑️ рядом с задачей
5. **Фильтрация**: Используйте кнопки "Все", "Активные" или "Завершённые" для фильтрации списка
6. **Очистка завершённых**: Нажмите кнопку "Очистить выполненные" в статистике для удаления всех выполненных задач

### Горячие клавиши

- **Enter** - добавить/сохранить задачу (в режиме редактирования)
- **Escape** - отменить редактирование

## 🔧 Как работает приложение

### Архитектура

Приложение построено на основе компонентного подхода React с использованием функциональных компонентов и хуков. Главный компонент `App.jsx` управляет состоянием всего приложения и передаёт данные и функции обработки событий дочерним компонентам через props.

### Управление состоянием

Все данные о задачах хранятся в состоянии компонента `App` с помощью хука `useState`:

```javascript
const [todos, setTodos] = useState([]);
```

Каждая задача представляет собой объект со следующей структурой:

```javascript
{
  id: Date.now(),        // Уникальный идентификатор
  title: "Текст задачи", // Текст задачи
  completed: false       // Статус выполнения
}
```

### Сохранение данных

Приложение использует `localStorage` браузера для сохранения задач. При загрузке приложения данные восстанавливаются из `localStorage`, а при каждом изменении списка задач автоматически сохраняются.

**Механизм работы:**

1. При монтировании компонента `App` данные загружаются из `localStorage`
2. Используется флаг `isLoaded` для предотвращения записи пустых данных при первой загрузке
3. При каждом изменении массива `todos` данные автоматически сохраняются через `useEffect`

### Компоненты

#### 1. TodoInput

Компонент для ввода новых задач. Включает:

- Поле ввода с валидацией
- Кнопку добавления
- Отображение ошибки при попытке добавить пустую задачу
- Обработку нажатия Enter для добавления

#### 2. TodoList

Компонент-контейнер для отображения списка задач. Включает:

- Отображение отфильтрованных задач
- Сообщения для пустого списка
- Рендеринг компонентов `TodoItem` для каждой задачи

#### 3. TodoItem

Компонент отдельной задачи с расширенным функционалом:

- **Отображение задачи** - чекбокс, текст, кнопки управления
- **Режим редактирования** - переключение между просмотром и редактированием
- **Анимация удаления** - плавное исчезновение при удалении (400ms)
- **Визуальная обратная связь** - стилизация для завершённых задач (зачёркивание текста)
- **Клавиатурная навигация** - Enter для сохранения, Escape для отмены

#### 4. TodoFilters

Компонент фильтрации задач с тремя режимами:

- **Все** - отображение всех задач
- **Активные** - только невыполненные задачи
- **Завершённые** - только выполненные задачи

Фильтрация происходит на уровне компонента `App` перед передачей данных в `TodoList`.

#### 5. TodoStats

Компонент статистики, отображающий:

- Общее количество задач
- Количество активных задач
- Количество завершённых задач
- Кнопку очистки завершённых задач (появляется только при наличии завершённых)

### Функции управления задачами

#### addTodo(title)

Создаёт новую задачу и добавляет её в начало списка. Валидация пустых строк выполняется перед добавлением.

#### toggleTodo(id)

Переключает статус выполнения задачи по её идентификатору. Использует `map` для создания нового массива с обновлённой задачей.

#### updateTodo(id, newTitle)

Обновляет текст задачи. Также использует `map` для создания нового массива.

#### deleteTodo(id)

Удаляет задачу из списка. Использует `filter` для создания нового массива без указанной задачи.

#### clearCompleted()

Удаляет все завершённые задачи одной операцией.

### Стилизация

Приложение использует CSS Modules для изоляции стилей компонентов. Это предотвращает конфликты имён классов между компонентами.

**Особенности стилизации:**

- Градиентный фон страницы
- Анимации появления элементов (fadeInScale, slideIn)
- Плавные переходы при взаимодействии
- Адаптивный дизайн с медиа-запросами
- Анимация зачёркивания для завершённых задач
- Анимация удаления элементов

### Фильтрация

Логика фильтрации реализована в компоненте `App`:

```javascript
const filteredTodos = todos.filter((todo) => {
  if (filter === 'active') return !todo.completed;
  if (filter === 'completed') return todo.completed;
  return true;
});
```

Отфильтрованный массив передаётся в компонент `TodoList`, который рендерит только соответствующие задачи.
